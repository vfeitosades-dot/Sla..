# Horizon Pocket VR — Redmi 10C

Protótipo experimental de interface VR inspirada em sistemas de realidade virtual, desenvolvido para smartphones Android e VR Box.

**Status:** protótipo. O rastreamento de cabeça sem giroscópio e o rastreamento de mãos ainda não estão validados no Redmi 10C. Não é um produto oficial da Meta.

O arquivo APK e o projeto Android precisam ser enviados separadamente. Este repositório ainda não contém um APK verificado.
